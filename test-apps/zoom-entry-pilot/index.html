Which technique stops tap-to-zoom?

On the iPad: in each box, TAP THE ANIMALS AS FAST AS YOU CAN — the way a child plays. If the page zooms in, that box's technique FAILED. Then try to PINCH in and out inside each dashed area and note what happens. Sounds play on finger-DOWN, so a "beep" means the tap registered.

A — what the apps ship today

touch-action: manipulation on html + body. Pinch works (both ways), double-tap zoom is supposed to be off — this is the control.

pinch test — zoom IN then OUT

B — panning only, no zoom at all

touch-action: pan-x pan-y (one CSS value, no JavaScript). Scrolling stays; pinch AND double-tap are both supposed to be refused — no way in, so no way to be trapped.

pinch test — can you zoom at all?

C — double-tap guard on top of today's rule

manipulation + a tiny script that cancels the second tap of a fast pair only. First taps, pinches and scrolling untouched. Taps score on finger-down, so rapid play keeps working.

pinch test — zoom IN then OUT

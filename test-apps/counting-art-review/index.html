What ships today

Three problems visible above.
1. The series has holes. 5, 8, 12, 13, 14, 17, 18, 19 were never drawn, so a child counting through the dictionary hits a blank at five. That set is not a design — it is whatever Spelling Exam’s word list happened to contain.
2. It is two visual languages, split 3 against 9. Only 1, 2, 3 are painted apple counts with no numeral. The other nine are sticker art with a large printed digit. The minority style is the one that looks like the rest of the dictionary.
3. Every numbered card counts a different object — stars, dots, flowers, leaves, crayons, carrots, fish, cookies, hearts. Counting is easiest when only the number changes.
An open decision, not a rule. Whether a counting card should show the printed numeral is a design question for the owner. The repository’s source-preference rule keeps printed words off dictionary cards — it says nothing about digits, and a digit beside the objects may well help a child link numeral to quantity. Decide it deliberately and apply it to all ten; today’s split is an accident of which app happened to supply each picture.

How to judge it

  1. Landscape 4:3, always. This is the whole reason the cards broke. Portrait art gets cropped to a band (which deleted apples) or padded (which shrinks it). Landscape art needs neither, and lands about twice the size.
  2. Count it at true size, not zoomed. If you have to lean in, a child cannot do it.
  3. Objects must be separated, never overlapping. A child counts by pointing at each one. Two apples touching read as one blob.
  4. Settle the numeral question once, then hold it for all ten. Today 9 of 12 show a digit and 3 do not, which is an accident rather than a choice. Either is defensible; the mixture is not.
  5. One visual language across all ten. Same objects, same style, same ground, so 1–10 reads as a series rather than a collection.
  6. Same object throughout, ideally. Counting is easier when only the number changes.
